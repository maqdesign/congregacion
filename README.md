# Mi Congregación

Aplicación gratuita de Holoteles destinada a consultar anuncios, reuniones, asignaciones, eventos y actividades de una congregación mediante una Cuenta Holoteles verificada. La marca Holoteles se presenta de forma discreta, no publicitaria.
